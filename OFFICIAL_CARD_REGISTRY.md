## Card-Rules Classification: INHERENT STAT RULE

Definition:
An Inherent Stat Rule is part of how a character's ATK and DEF are determined. It is not a special ability.

Rules:
- An Inherent Stat Rule cannot be canceled, disabled, copied, stolen, or removed by Rogue, ability-cancel effects, or any future ability-suppression mechanic.
- A character with an Inherent Stat Rule never has blank, N/A, or missing battle stats merely because its special abilities are disabled.
- Resolve a character's Inherent Stat Rule before battle stat comparison.
- Any future card that has no fixed printed base stats must use this classification instead of being treated as an ability-only card.
- For future digital design, card data must keep statRule separate from ability.

## Alpha Exclusion Notes for Inherent Stat Rule Cards

- THE MOON is excluded from first alpha because real-time stat calculation is not implemented yet.
- RIDDLER is excluded from first alpha because bottom-deck stat resolution is not implemented yet.
- LOKI is excluded from first alpha unless dynamic board-based stat calculation is deliberately added.

## Future Digital Stat Resolution Order

1. Resolve inherent stat rule, if any.
2. Apply permanent stat modifiers.
3. Apply equipped-item / attachment modifiers.
4. Apply temporary battle modifiers.
5. Compare final battle stats.
